# Sales Management System

Sales Management System is a desktop based applic
ation developed on `C#` programming language.


Management of sales, purchases, employee affairs and clients, in addition to printing a report, according to profits and expenses. You can control the management of a bank and a safe, and separate roles between employees. Each employee can be given powers as you want and many of the features make it easier for you to manage your products, saving you time and effort.

Sales Management System has been developed as coursework of Application Development module.
The main objectives of this project are:

- Learn basic concept of Object Oriented Programming.
- Learn Windows Form Application.

## Features

- Light/dark mode toggle.
-  System users can ` add employee,customer and supplier,Products details`.
- System users can  `edit and update employee,customer and supplier, Products details` .
- System users can  `calculate the total profits, expenses and salaries of employees`.
- System users can `generate a report for all sections of the program`.
- System users can `print invoices and barcodes`.
- System users can `add, delete and modify and update`.
- System users can  `control user permissions`.
## Tech Stack

**Client:** [MaterialSkin.2](https://www.nuget.org/packages/MaterialSkin.2/)  , [LiveCharts.0.9.7](https://www.nuget.org/packages/LiveCharts.Wpf.NetCore3/),  [WinFormAnimation](https://www.nuget.org/packages/WinFormAnimation/1.3.0),WinForms

**Server:** Sql Server 2019 , C# 

**Vrsion :** ` .NET framework 4.7.2 `
